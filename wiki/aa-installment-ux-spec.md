# AA 与分期账单体验优化规格

## Objective

优化 PWA/H5 下 AA、分期账单的新增和查看体验：让用户能快速看懂当前模式、金额拆分和待办操作，并让首页账单卡片与分期详情页具备清晰的状态层级。保持现有账单字段、余额重算、统计口径、导入导出兼容性和整组维护规则不变。

## Scope

- 记账页：重组 AA 与分期入口，显示金额拆分、每期预估和互斥状态。
- 首页：为 AA 付款显示应收/待收，并提供直接新增 AA 还款入口；为分期显示更清晰的组标签。
- 分期详情页：增加组摘要、进度、已发生/待发生金额和每期状态视觉。
- README：同步记录新增的用户可见能力。

## Commands

- 类型检查：`pnpm type-check`
- 正式 PWA 构建（会按项目规则自增版本）：`pnpm build:h5`

## Boundaries

- Always：通过现有 `billStore` 入口保存或读取数据；保持移动端优先和现有玻璃风格。
- Ask first：改变账单数据结构、统计金额、余额计算、导入导出字段或新增依赖。
- Never：清空本地数据、绕过 store 写入账单、提交密钥或真实账本数据。

## Success Criteria

- AA 开启后能在同一视觉区域看到“总额 / 本人承担 / 待收”，并能直接进入 AA 还款。
- 分期开启后能看到“总额 / 手续费 / 期数 / 每期约”，且明确提示与 AA 互斥。
- 首页 AA 付款卡片能看到结算状态；待收大于 0 时可直接进入还款录入。
- 首页分期卡片能看到期数信息；分期详情能看懂组总额、进度、每期金额和已到期状态。
- `pnpm type-check` 通过；正式构建如执行则通过且版本同步脚本正常工作。
